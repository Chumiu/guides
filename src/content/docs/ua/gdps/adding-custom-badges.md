Це руководство покаже вам як додавати власні бейджики вашим гравцям всередині гри використовуючи [мод GDPS Badges](https://geode-sdk.org/mods/m336.gdps-badges)!

![Приклад моди з профілю](../../../../assets/gdps/adding-custom-badges/preview-image.webp)

![Приклад мода в інтерфейсі бейджиків](../../../../assets/gdps/adding-custom-badges/preview-image-2.webp)

*Це руководство більше призначене для власників/адміністраторів GDPS; якщо ви просто звичайний гравець, ви повинні зачекати, поки ваша GDPS оголосить про сумісність з цим модом, щоб бачити кастомні бейджики, додані всередину гри.*

## Умови
Щоб продовжити роботу з цим посібником, вам потрібно переконатися, що:
- Ви маєте повний доступ до SFTP вашого GDPS;
- Ви вже створили кілька власних бейджів, які хочете додати (Адже в цьому й полягає суть цього посібника… чи не так? *Необхідна роздільна здатність — 92×92, мод підтримує лише формат PNG.*)

## Створення файлу badges.json
У SFTP перейдіть до кореневого каталогу public вашого GDPS (зазвичай `public_html`) і створіть нову папку з назвою `badges`; саме туди ви будете встановлювати властивості для своїх бейджів та додавати їхні текстури.

У папці `badges` створіть файл `badges.json` і заповніть його, дотримуючись цього прикладу:
```json
[
    {
        "id": "owner",
        "name": "Owner",
        "description": "Це <cr>власник</c> цієї GDPS!",
        "requirements": {
            "players": [ 72 ]
        }
    },
    {
        "id": "demon-grinder",
        "name": "Demon Grinder",
        "description": "Цей гравець переміг понад <cr>2,500</c> рівнів складності Demon!",
        "requirements": {
            "minDemons": 2500,
            "maxDemons": 9999
        }
    }
]
```

### Можливі умови
| Параметр | Опис | Приклад |
| --- | --- | --- |
| `players` | Білий список ідентифікаторів облікових записів, для яких може відображатися значок | `"players": [ 72, 73, 74 ]` |
| `modBadge` | Додайте користувацький значок, якщо присутній один із значків модератора. Це може бути або `leaderboard`, `elder`, або `regular` | `"modBadge": "elder"` |
| `minRank` | Мінімальний глобальний рейтинг, необхідний для отримання значка | `"minRank": 1` |
| `maxRank` | Максимальний глобальний рейтинг, необхідний для отримання значка | `"maxRank": 100` |
| `minStars` | Мінімальна кількість зірок, необхідна для отримання значка | `"minStars": 1000` |
| `maxStars` | Максимальна кількість зірок, необхідна для отримання значка | `"maxStars": 5000` |
| `minMoons` |  Мінімальна кількість місяців, необхідна для отримання значка | `"minMoons": 500` |
| `maxMoons` |  Максимальна кількість місяців, необхідна для отримання значка | `"maxMoons": 2000` |
| `minGoldCoins` |  Мінімальна кількість секретних монет, необхідна для отримання значка | `"minGoldCoins": 50` |
| `maxGoldCoins` | Максимальна кількість секретних монет, необхідна для отримання значка | `"maxGoldCoins": 164` |
| `minSilverCoins` | Мінімальна кількість користувацьких монет, необхідна для отримання значка | `"minSilverCoins": 100` |
| `maxSilverCoins` | Максимальна кількість користувацьких монет, необхідна для отримання значка | `"maxSilverCoins": 500` |
| `minDemons` | Мінімальна кількість пройдених демонів, необхідна для отримання значка | `"minDemons": 10` |
| `maxDemons` | Максимальна кількість пройдених демонів, що дає право на отримання значка | `"maxDemons": 100` |



## Додавання іконок бейджів
Тепер просто перенесіть текстури, які у вас є, до папки `badges`.
Переконайтеся, що її назва збігається з ідентифікатором, який ви вказали для відповідного значка у файлі `badges.json`!

Наприклад, якщо ви хочете додати текстуру для значка «Demon Grinder», показаного вище, вам потрібно перетягнути файл із назвою `demon-grinder.png`.
![Файли в папці badge у SFTP](../../../../assets/gdps/adding-custom-badges/sftp-example.webp)

## Обмін модом
Тепер просто повідомте своїх гравців, що ваш GDPS тепер сумісний із модом:
- Або шляхом [ручної установки](https://geode-sdk.org/mods/m336.gdps-badges) та переміщення файлу в папку з модами,
- Або, всередині гри, завантажуйте його **з index**, як показано нижче:
![Завантаження значків GDPS із каталогу модів Geode](../../../../assets/gdps/adding-custom-badges/download-from-index.webp)
