Это руководство покажет вам как добавлять кастомные бейджики вашим игрокам внутри игры используя [мод GDPS Badges](https://geode-sdk.org/mods/m336.gdps-badges)!

![Пример мода из профиля](../../../../assets/gdps/adding-custom-badges/preview-image.webp)

![Пример мода в интерфейсе бейджиков](../../../../assets/gdps/adding-custom-badges/preview-image-2.webp)

*Это руководство более предназначано для владельцев/администраторов GDPS; если вы всего лишь обычный игрок, вы должны подождать, когда ваша GDPS заанонсит совместимость с этим модом, чтобы видеть кастомные бейджики добавленные внутрь игры.*

## Условия
Чтобы продолжить работу с данным руководством, вам необходимо убедиться, что:
- У вас есть полный доступ к SFTP вашего GDPS;
- Вы уже нарисовали несколько кастомных бейджиков, которые вы хотите добавить (Как-никак, в этом и суть этого руководства.. разве не так? *Необходимое разрешение это 92х92, мод поддерживает только формат PNG.*)

## Создание badges.json
В SFTP, зайдите в корень public вашего GDPS (обычно `public_html`) и создайте новую папку под названием `badges`; это где вы установите свойства для ваших бейджиков и добавлять их текстуры.

Внутри папки `badges`, создайте файл `badges.json` и заполните его следуя этому примеру:
```json
[
    {
        "id": "owner",
        "name": "Owner",
        "description": "Это <cr>владелец</c> этого GDPS!",
        "requirements": {
            "players": [ 72 ]
        }
    },
    {
        "id": "demon-grinder",
        "name": "Demon Grinder",
        "description": "Этот игрок одолел более <cr>2,500</c> уровней сложности Demon!",
        "requirements": {
            "minDemons": 2500,
            "maxDemons": 9999
        }
    }
]
```

### Возможные условия
| Параметр | Описание | Пример |
| --- | --- | --- |
| `players` | ID аккаунтов, для которых может отображаться бейджик | `"players": [ 72, 73, 74 ]` |
| `modBadge` | Кастомный бейджик, если есть бейджик модератора. Значение может быть `leaderboard`, `elder`, или `regular` | `"modBadge": "elder"` |
| `minRank` | Минимальный глобальный рейтинг, необходимый для получения бейджика | `"minRank": 1` |
| `maxRank` | Максимальный глобальный рейтинг, необходимый для получения бейджика | `"maxRank": 100` |
| `minStars` | Минимальное количество звёзд, необходимое для получения бейджика | `"minStars": 1000` |
| `maxStars` | Максимальное количество звёзд, необходимое для получения бейджика | `"maxStars": 5000` |
| `minMoons` |  Минимальное количество лун, необходимое для получения бейджика | `"minMoons": 500` |
| `maxMoons` |  Максимальное количество лун, необходимое для получения бейджика | `"maxMoons": 2000` |
| `minGoldCoins` |  Минимальное количество секретных монет, необходимое для получения бейджика | `"minGoldCoins": 50` |
| `maxGoldCoins` | Максимальное количество секретных монет, необходимое для получения бейджика | `"maxGoldCoins": 164` |
| `minSilverCoins` | Минимальное количество пользовательских монет, необходимое для получения бейджика | `"minSilverCoins": 100` |
| `maxSilverCoins` | Максимальное количество пользовательских монет, дающее для получения бейджика | `"maxSilverCoins": 500` |
| `minDemons` | Минимальное количество пройденных демонов, необходимое для получения бейджика | `"minDemons": 10` |
| `maxDemons` | Максимальное количество пройденных демонов, дающее право на получение бейджика | `"maxDemons": 100` |

## Добавление иконок бейджика
Теперь, просто перенесите текстуры, которые у вас есть, в папку `badges`.
Убедитесь, что его название совпадает с идентификатором, который вы указали для соответствующего бейджика в `badges.json`!

Например, если вы хотите добавить текстуру для бейджика «Demon Grinder», показанного выше, вам нужно перетащить файл с именем `demon-grinder.png`.
![Файлы в папке badge в SFTP](../../../../assets/gdps/adding-custom-badges/sftp-example.webp)

## Обмен модом
Теперь, просто информируйте ваших игроков что ваш GDPS теперь совместим с модом:
- Либо через [вручную установку](https://geode-sdk.org/mods/m336.gdps-badges) и перемещение файла в папку с модами,
- Либо, внутри игры, скачивайте его **из index** как показано внизу:
![Загрузка бейджиков GDPS из каталога модов Geode](../../../../assets/gdps/adding-custom-badges/download-from-index.webp)
